Project overview

An early personal electronics project: I assembled and programmed a small remote-controlled car using an Arduino board, a breadboard and an HC-06 Bluetooth module.

The central task was to turn wireless commands into motor movement through an embedded controller, learning about wiring, PWM/servo actuation and serial communication along the way.

  • Integrated an HC-06 serial Bluetooth communication module.

  • Controlled motion direction and stop behaviour with the embedded program.

What is documented

The core completed feature is Bluetooth remote control. An earlier draft of this site mentioned fully autonomous obstacle avoidance, but I have not included that as a verified outcome.

This project is intentionally described more briefly than later university work. It shows the beginnings of my interest in physical computing and control.
