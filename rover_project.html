Project & my role

RoverTech is an extracurricular PoliSpace student project preparing for the European Rover Challenge. I work on arm manipulation and camera-based interaction with a maintenance panel in the Gazebo simulation.

My contribution includes integrating an Orbbec Gemini 305 RGB-D camera, configuring the simulated panel markers, implementing ArUco-based pose estimation, and connecting perception to the manipulator pre-approach workflow.

Perception-to-motion pipeline

RGB-D camera
→

→
solvePnP + TF2
→
Target localization
→
MoveIt 2 planning
  • Panel search: an initial demonstration tests a sequence of predefined observation poses and triggers marker detection.
  • Pose estimation: marker correspondences and camera intrinsics support 3D panel pose estimation using solvePnP.
  • RGB-D interaction: known panel geometry and depth information help localize individual controls.
  • Manipulator motion: planning a collision-aware pre-approach toward the main switch using MoveIt 2.
