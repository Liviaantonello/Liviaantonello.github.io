Autonomous Vehicle Control & Learning

Ongoing simulated track-following project investigating how neural networks can generate vehicle steering and acceleration commands.

Vehicle dynamicsDistance sensingNeural-network controlSimulation

Research question

Can a simulated autonomous vehicle learn how to follow a predefined circuit using distance measurements and a neural-network controller?

This project is being developed within an autonomous vehicle control course. The learning controller and its performance are still under investigation; no successful training results are presented yet.

Planned technical approach

4 distance sensors
→
Neural network
→
Steering + acceleration
→
Vehicle dynamics
01
Vehicle model
Use a simplified dynamic model (including pose, heading and velocity) to simulate the response to control inputs.
02
Observations
Estimate where the vehicle is relative to the track using four distance measurements.
03
Learning
Investigate an NN-based policy producing steering and acceleration.
04
Evaluation
Assess tracking error and driving behaviour over simulated laps; compare against a reference trajectory.

Status and evidence

Ongoing coursework. This page currently documents the intended architecture and study goals. The learning method, software framework and results will be added only when implementation and validation are complete.
